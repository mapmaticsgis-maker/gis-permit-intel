# RROG Client Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single self-contained `RROG_Dashboard.html` that shows RROG's operator client (Apex, v1) the abstract/title status, leasing funnel, ownership position, and an interactive lease/abstract-status map for each of three Haynesville units, regenerated by a Python build script from the MOR workbooks RROG emails.

**Architecture:** A lean `rrog/` package of single-responsibility parsers + a geometry module + a renderer, orchestrated by `build_rrog_dashboard.py` which holds a `CONFIGS` table (client → unit → sections). Each parser takes a real workbook path and returns typed dataclasses; the renderer assembles one payload and substitutes it into `template.html` (Leaflet inlined). Output is one static HTML file that works offline. This diverges from the single-file Doxa/Flatland build pattern on purpose — three distinct workbook schemas plus per-section geometry discovery justify the split; the deliverable and rebuild story stay identical (one command, one HTML).

**Tech Stack:** Python 3.13 on the ArcGIS Pro conda env (`C:\Program Files\ArcGIS\Pro\bin\Python\envs\arcgispro-py3\python.exe`) — `pandas` 3.0, `openpyxl` 3.1.5, `osgeo` (GDAL), `PIL`, `pytest` 8.4.2 all present. Leaflet 1.9.4 (vendored, inlined). No new installs.

- **Interpreter:** always the ArcGIS Pro Python above. System Python 3.14 has broken `openpyxl`/`numpy` and no GDAL. Every `Run:` and build command uses the full path (alias it `PYEXE` in your shell).
- **Deliverable:** one file, `C:\GIS\CLIENT\RROG\DASHBOARD\RROG_Dashboard.html`, opens by double-click, works offline. No external requests except basemap tiles.

- **Canonical funnel vocabulary + colors** (normalize every workbook's wording to this):

  | `working` | Working (letter sent) | `#00B0F0` | "Working-Letter Sent", `COLOR=B` |

`UnitData` (in `rrog/__init__.py`) is the contract every workbook parser returns:

```python
from dataclasses import dataclass, field

@dataclass
class FunnelTotals:
    # bucket key -> {"tracts": int, "net_acres": float, "pct": float, "sub": {name: {...}}}
    by_bucket: dict
    unit_acres: float
    source_sheet: str

@dataclass
class TractRecord:
    tract_id: str            # canonical, e.g. "40-199", "3A", "22-31"
    section: str             # e.g. "36-T16N-R14W"
    gross_acres: float | None
    net_mineral_acres: float | None
    unit_pct: float | None
    bucket: str | None       # canonical funnel key
    owners: list             # [{"name","nma","lessee","royalty","ogml_inst","dates","comment"}]
    abstract_status: str | None   # "complete" | "in_review" | "working" | None
    comments: list

@dataclass
class AbstractPackage:
    key: str                 # RROG's own package string, verbatim
    tract_ids: list          # expanded canonical ids
    acres: float | None
    name: str | None
    status: str | None       # "complete" | "in_review" | "working"
    rrog_abstract_no: str | None
    cert_date: str | None
    comments: str | None

@dataclass
class TitleOpinion:
    key: str
    tract_ids: list
    acres: float | None
    name: str | None
    opinion_date: str | None
    certification_date: str | None
    attorney: str | None
    opinion_type: str | None

@dataclass
class InterestPosition:
    # owner -> {"wi_bpo","wi_apo","nri_bpo","nri_apo","net_acres"}
    owners: dict
    client_owner_key: str     # "APEX NATURAL GAS, LLC"

@dataclass
class UnitData:
    unit_label: str          # "Unit 76"
    unit_field: str          # "HA RA SU85 / HA RA SUX"
    sections: list            # ["36-T16N-R14W", ...]
    parish: str
    report_date: str          # "2026-02-05"
    funnel: dict              # section key -> FunnelTotals ; plus "_cross_unit" for U76
    tracts: list              # list[TractRecord]
    abstract_packages: list   # list[AbstractPackage]
    title_opinions: list      # list[TitleOpinion]
    interest: InterestPosition
    notes: list               # caveats to render on the page (e.g. "TO inventory empty this cycle")
```
