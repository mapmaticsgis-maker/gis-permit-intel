# Flatland North — Tract Intelligence Dashboard

**Date:** 2026-08-27
**Client:** EOG / DLS — Flatland North T1 Prospect, Lee County, Texas
**Deliverable:** `C:\GIS\CLIENT\DLS\DASHBOARD\Flatland_North_Dashboard.html`

## 1. Purpose

A single self-contained HTML page that lets the DLS/EOG land team read the
Flatland North T1 leasing position at a glance: a tabbed analytics panel built
from the `Tracts` tab of `Tract_Report_Flatland_North_T1_8-18-26.xlsx` on the
left, and an interactive, zoomable lease-status map on the right. Static
point-in-time snapshot of the 8-18-26 report — no server, no live data, no
editing.

## 2. Deliverable form

- One file, `Flatland_North_Dashboard.html`, ~6–10 MB, opens by double-click.
- Leaflet 1.9.4 JS + CSS inlined; all app CSS/JS inlined; all vector data
  embedded as GeoJSON literals.
- Works offline. Online basemap tiles load when a connection exists; when they
  fail the map falls back to a neutral canvas so polygons, labels and context
  layers stay usable.
- Subtle Mapmatics wordmark in the header (from `Desktop\DESIGN\mm`), theme-aware.
- Regenerated by `build_flatland_dashboard.py` kept in the same folder.

## 4. Build script — `build_flatland_dashboard.py`

Runs on the ArcGIS Pro Python (`C:\Program Files\ArcGIS\Pro\bin\Python\envs\arcgispro-py3\python.exe`)
— it has `osgeo` (ogr/osr), `pandas`, `openpyxl`. No new installs.

Steps:
1. Read the `Tracts` tab → normalize ~18 fields per record (UID, TRACT_NO,
   OFFER_STAT, LEASE_STAT, TITLE STATUS, UNIT STATUS, RS_STATUS, OPERATOR,
   LESSEE, COUNTY, SURVEY, ABSTRACT NO., TRUE/LEASE/GIS acres, NET ACRES,
   MINERAL INTEREST, TOTAL BONUS, TOTAL BONUS /W FEE, TOTAL OPTION AMOUNT,
   BONUS/NMA, ROYALTY, EXPIRATION BY QTR, LEASE DATE, LEASE EXPIRATION,
   LEASING/TITLE COMMENTS, BROKER). Clean the known typo `In Progess`→`In Progress`.
2. Read shapefile #2, reproject → 4326, build a `{UID: geometry}` map.
3. Emit `TRACTS_GEO`: FeatureCollection, one feature per UID, `properties` =
   the normalized record, `geometry` from step 2. Drop the ~1 record with no
   geometry match (log it).
4. Read #3 → `UNITS_GEO` (properties: unit_nm, operator, FORMATION, COUNTY, acres).
5. Read #4 from the GDB, reproject NAD27→4326 → `SURVEYS_GEO`
   (properties: abstract_no, survey_name, abstract_label).
6. Read #5, filter to the 7 counties, reproject → `COUNTIES_GEO`
   (properties: name, is_subject `bool`).
7. Compute map extent = bounds of `TRACTS_GEO` + 5% pad.
8. Render `template.html` with all six data blocks + style config inlined,
   write `Flatland_North_Dashboard.html`.

Idempotent; safe to re-run when the report or shapefiles update.

## 5. Layout

CSS grid, two equal columns, `100vh`. Left = analytics, right = map. Below
~1100 px viewport width the columns stack (analytics first, map gets `70vh`).
Header spans both columns: title, Mapmatics mark, theme toggle, active-filter
chips, Reset button, record/acre counts for the current filter.

## 6. Theme

Light / dark, user-selectable via a header toggle. Implementation: CSS custom
properties on `:root` (light) and `:root[data-theme="dark"]`; default follows
`prefers-color-scheme`; choice persisted to `localStorage`
(`fln-dashboard-theme`), wrapped in try/catch. Map basemap swaps to a
dark-appropriate tile set in dark mode; polygon symbology (below) keeps its
lease-status colors in both themes but strokes/labels use theme tokens.

## 7. Left panel — analytics (tabbed)

Four tabs, each a full scrollable panel. All figures recompute live against the
current filter set.

### Tab A — Acreage Position
- Stat tiles: tract count, gross ac (TRUE), leased-gross ac, GIS ac, net ac,
  avg mineral interest.
- Horizontal bar: GIS acres by `LEASE_STAT` (Open / Partial HBP / EOG HBP /
  Competitor), colored by the lease-status palette.
- Horizontal bar: net acres by `OPERATOR` (top 8 + Other).
- Horizontal bar: GIS acres by `SURVEY` (top 12).

### Tab B — Leasing Pipeline
- Funnel (counts + net acres): Open → Attempting to Contact → Contact Made →
  Negotiating → Committed → Signed.
- Stat tiles: open tracts, open net ac, competitor tracts, competitor net ac,
  EOG HBP net ac.
- Horizontal bar: competitor acreage by `LESSEE` (top 10).
- Horizontal bar: open net acres by `SURVEY` (top 12) — where to work next.

### Tab C — Title Progress
- Donut: title status in the 5-class `TITLE STATUS - FLATLAND NORTH.lyrx` scheme
  (Complete `#89CD66` / In Progress `#B7B6FC` / Need `#FFFFFF` / 3rd-party lease
  `#CDAA66` / Other `#828282`) by tract count — matches the map layer exactly.
- Stat tiles: % of tracts title-complete, % of net acreage title-complete,
  tracts needing title, in-progress count.
- **Title status — DLS unit (`UNIT / AREA 2`)**: this is EOG title work run by
  DLS, so an operator split is meaningless. Instead: a stacked bar per Area 2
  unit (title-class composition) plus a scrollable per-tract worklist (lessor /
  owner, UID, net ac, title-class swatch), sorted actionable-first
  (Need → 3rd-party → In Progress → Other → Complete), each row clicking through
  to the tract detail card. Grows automatically as more Area 2 units appear.
- Bar: `UNIT STATUS` (HBP vs blank/other) net acres.

### Tab D — Bonus / Exposure  *(shown where populated — 1,008 of 4,712 tracts)*
- Stat tiles: total bonus ($7.97 M), total bonus w/ fee, total option amount,
  tracts with a bonus figure, weighted avg $/NMA.
- Histogram: `BONUS/NMA` distribution (buckets).
- Horizontal bar: total bonus by `LEASE_STAT`.
- Note line stating coverage (only ~21% of tracts carry a bonus value).

Chart rendering: hand-built inline SVG (horizontal bars, donut, histogram) —
no chart library. Follows the `dataviz` skill palette/entrance rules. Bars are
clickable → adds the corresponding filter.

## 8. Shared filter bar

One control strip above the tabs. Fields: Lease status, Offer status, Operator,
Lessee, Survey, Title status, Expiration quarter. Each is a multi-select
dropdown of the distinct values with counts. Selecting values, or clicking a
chart bar / map polygon category, updates one shared `filterState` object that
drives **both** panels. Active filters render as removable chips in the header;
Reset clears all.

## 9. Right panel — map

- Leaflet, `preferCanvas: true` (canvas renderer — smooth pan/zoom with 4,712
  polygons; no functionality lost at any zoom level). `zoomSnap: 0.25`.
- **Panes / draw order (bottom → top):** basemap tiles → counties →
  surveys → tracts (lease status) → units → highlight.
- **Basemap** (radio in layer control, graceful offline fallback) — keyless
  sources only, no API key: OpenStreetMap / Esri World Imagery / Esri World Topo /
  OpenTopoMap / None (survey grid only). Default: OSM in light, None in dark.
  CARTO basemaps dropped — they now key-gate and return "API Key Required" tiles.
- **Overlay layers** (checkboxes, independently toggleable):
  - Tracts — Lease Status (on) — styled per `LEASE STATUS - FLATLAND NORTH.lyrx`
  - Tracts — Title Status (off) — **same GeoJSON source**, styled per
    `TITLE STATUS - FLATLAND NORTH.lyrx` (compound key `OFFER_STAT` + `TTL_STATUS`:
    Complete `#89CD66`, In Progress `#B7B6FC`, Need `#FFFFFF`, 3rd-party lease
    `#CDAA66`, all-other `#828282`). Own pane, drawn just above the lease layer.
  - Units — Operator (on) — drawn **above** both tract layers, fill opacity 100%
  - Surveys — Lee Co land grid `surv287p` (**on by default**; the vector backdrop,
    faint lines + hover survey/abstract label)
  - Counties (on; hairline + county name labels, subject county emphasized)
- **Opacity sliders** in the layer panel for the Tracts and Units fills
  (Tracts default 62%, Units default 100%).
- **Symbology — ported verbatim from the `.lyrx` files:**
  - Tracts on `OFFER_STAT`: EOG HBP/Signed `#FFFF00`, Committed `#55FF00`,
    Negotiating `#FFAA00`, Contact Made `#66CCFF`, Attempting to Contact
    `#CCECFF`, Competitor `#CDAA66`, Partial HBP `#CCCCCC`, Open `#FFFFFF`,
    default `#828282`. Fill opacity 0.55, 0.6 px black stroke.
  - Units on `operator`: EOG `#FFFF00`, SAGE `#B4D79E`, MAGNOLIA `#0070FF`,
    TEX-LEE `#FF73DF`, LEEXUS `#FFD37F`, 3rd-party HBP group `#9C9C9C`,
    default `#ECBDF2`. Fill opacity 0.20, 1.5 px black stroke (outline-forward
    so tracts read underneath).
- **Legend:** lives inside the single "Layers & legend" panel (top-right,
  scrolls internally), sections shown for whichever layers are on. No separate
  floating legend box.
- **Header wordmark:** the current "MAPMATICS GIS" lettering pulled from
  mapmatics.co (`assets/images/image07.png`), vendored to `vendor/mm_logo.png`;
  white glyphs, CSS-inverted to dark in light theme.
- **Popups / interaction:** tract → attribute card + detail slide-over.
  **Units are hover-only** (tooltip: name, operator, formation, acres) and do
  **not** capture clicks — a click on a unit is ray-cast to the tract beneath it
  and opens that tract's detail, so tracts stay selectable everywhere. Survey →
  hover name + abstract label; county → name popup.

## 10. Linking (both ways)

- **Left → map:** applying any filter fades non-matching tract polygons to 0.08
  opacity (kept for context, not removed) and the map animates a `fitBounds` to
  the matching set. Unit/survey/county layers are unaffected.
- **Map → left:** clicking a tract polygon opens a slide-over **Tract Detail**
  card over the analytics panel showing every field for that UID, and outlines
  that polygon in the highlight pane. Closing the card returns to the tabs.
- Clicking a chart bar (e.g. a `SURVEY` bar in Tab A) adds that value to
  `filterState`, which immediately reflects on the map.

## 11. Out of scope

Live/refreshing data, editing or write-back, authentication, multi-prospect
support, print/PDF export, mobile-first layout (usable but not optimized).

## 12. Risks / notes

- File size: 4,712 tract polygons dominate. Mitigations: topology-preserving
  simplify, 6-dp coordinate rounding, minified GeoJSON. Target < 10 MB; if it
  exceeds, drop to 5-dp and increase simplify tolerance.
- `surv287p` is NAD27 — must set source CRS explicitly (GDB stores it, verified
  EPSG:4267) and transform, or surveys will sit ~100–200 m off the tracts.
- `TRUE GROSS AC` is 0 for ~2,264 rows; acreage tiles that need a gross figure
  fall back to `LEASE GROSS AC` then `GIS AC`, and the tile labels say which.
- One `Tracts` row has no polygon match — logged and excluded from the map,
  still counted in analytics totals with a footnote.
